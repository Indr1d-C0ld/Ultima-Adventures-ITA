To play "Offline" or host your own server:
1. Launch the "Adventures Server.exe"
2. After several seconds, the server should be available for log in.

The package may be stored on any drive. Keep the Client and Server folders as
siblings when extracting the complete package.

Notes:
- If you change anything under the "Server\Server" folder, you must run the
  "Compile new exe.bat".
- If you change anything under the "Server\Scripts" folder, you must restart
  the server executable.
